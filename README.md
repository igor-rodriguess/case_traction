# case_traction
Agente de IA para investigação de solicitações industriais, integrado à API da TRACTIAN. A solução usa LangGraph, tool calling e raciocínio guiado por evidências para consultar dados, gerar respostas confiáveis, registrar a trajetória da investigação, realizar human handoff quando necessário e avaliar a qualidade das decisões do agente.
